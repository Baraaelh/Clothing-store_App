# شعار تطبيق الأناقة الذكي

الشعار **ثابت ورسمي**: لا يُعاد رسمه ولا تُغيَّر ألوانه أو نسبه. كل الأحجام تُولَّد من ملفات SVG في هذا المجلد.

**الفكرة:** علّاقة ملابس (المحل والكاشير) خطّافها سهما مزامنة (التطبيق يعمل بدون إنترنت ويتزامن مع السيرفر والمتجر الإلكتروني)، والنجمة تعني "الذكي".

| اللون | الكود |
|---|---|
| كحلي | `#1B2A5C` |
| ذهبي | `#C9A24A` |
| ذهبي فاتح (النجمة) | `#E3C77E` |
| كريمي | `#F7F1E6` |

الخطوط: Cairo ExtraBold (عربي)، Poppins Bold (إنجليزي). النصوص في ملفات SVG محوّلة لأشكال.

| الملف | الاستخدام |
|---|---|
| `icon.svg` | أيقونة بزوايا مستديرة (أندرويد القديم، الويب) |
| `icon-square.svg` | أيقونة iOS (النظام يستدير الزوايا بنفسه) |
| `adaptive-foreground.svg` | واجهة أيقونة أندرويد 8+ على خلفية `#1B2A5C` |
| `logo-stacked*.svg` / `logo-horizontal*.svg` | الشعار مع الاسم، فاتح وداكن |
| `mark-gold.svg` / `mark-navy.svg` | الرمز وحده بدون خلفية |
